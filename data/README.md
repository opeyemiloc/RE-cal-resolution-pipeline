# `data/` — Pipeline Data Directory

This directory stores all input files, reference databases, and generated outputs. It is **excluded from Git** (via `.gitignore`) since it contains user-specific data.

## Subdirectories

### `input/`
Where uploaded Excel files are saved. The Streamlit app automatically writes files here when you upload through the GUI.

- **Master Accounts Excel** — Your reference list of known company names
- **Manifest Excel files** — Container Arrival Lists from shipping lines (MSC, Hapag, ONE, COSCO)

### `reference/`
Generated reference files used by the matching pipeline:

- `master_list_json.json` — Flat JSON array of master account names (auto-generated from the Master Accounts Excel by `master_parser.py`)
- `match_history.json` — Historical match decisions (future use)

### `output/`
Pipeline results and diagnostics:

- `pipeline_audit.json` — Timestamped log of each pipeline run (BLs processed, match counts, etc.)
- `1_raw_excel_data.json` — Raw parsed records (from `test_ingestion.py`)
- `2_unique_bl_records.json` — Deduplicated BL-level records
- `3_vector_math_debug.json` — Vector search distances and gatekeeper results
- `4_vector_passed_candidates.json` — Records that passed vector search
- `5_final_decisions.json` — Combined final match decisions

> **Note:** The numbered output files (`1_` through `5_`) are generated by `test_ingestion.py` (CLI test script). The Streamlit app generates results in-memory and displays them directly in the GUI.

## Folder Setup

These directories are created automatically by the pipeline. If starting fresh:

```bash
mkdir -p data/input data/output data/reference
```

Each folder contains a `.gitkeep` file to preserve the directory structure in Git while keeping actual data files ignored.
